# Test Process for a financial technology company

Draft outline.

A test process that connects requirement review, sprint testing, and release regression.

## Topics to develop

- Requirement review: clarify business rules and record open questions.
- Sprint testing: design functional tests and choose automation layers.
- Release regression: cover main user journeys and high-risk scenarios.
- Release decisions: review test results, defects, and unresolved risks.
